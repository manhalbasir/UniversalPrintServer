# UniversalPrint Server (Windows)

تطبيق ويندوز مرافق لتطبيق **UniversalPrinter** على أندرويد. يجعل طابعة
حاسوبك متاحة للهاتف عبر الشبكة المحلية، بطريقتين:

## البروتوكولان المدعومان

### 1. Samba/SMB (مشاركة ويندوز الكلاسيكية)
يفعّل مشاركة الطابعة عبر أمر `Set-Printer` الرسمي في PowerShell — نفس ما
تفعله يدويًا من "أجهزة وطابعات"، لكن بضغطة زر واحدة، مع تفعيل قاعدة جدار
الحماية اللازمة تلقائيًا.

**القيد:** يعمل فقط مع طابعات يستطيع **ويندوز نفسه** الطباعة عليها بشكل
طبيعي (أي طابعة مثبَّتة بتعريفها الصحيح تعمل من داخل ويندوز).

### 2. خادم RAW / JetDirect (منفذ 9100) — الأكثر توافقًا
هذا هو الجزء الأهم عمليًا: يُشغّل خادم TCP داخلي يستمع على المنفذ 9100
(نفس معيار AppSocket/JetDirect القياسي)، وأي بيانات يرسلها تطبيق الهاتف
إليه، يُمرّرها مباشرة إلى **طابور طباعة ويندوز الحقيقي** عبر Win32 API
(`winspool.drv`) — تمامًا كأن ويندوز نفسه هو من طبع الملف.

**لماذا هذا مهم:** لأنه يجعل **أي طابعة** — حتى الموصولة بكابل USB فقط بلا
أي دعم شبكي إطلاقًا — متاحة فورًا لتطبيق الهاتف، بما أن ويندوز يتولى كل
الترجمة والتوافق مع الطابعة الفعلية، والهاتف لا يحتاج معرفة أي شيء عن نوعها.

## المتطلبات للبناء

- Visual Studio 2022 (أو أحدث) مع حمولة عمل **".NET Desktop Development"**
- .NET 7 SDK (أو عدّل `<TargetFramework>` في الملف `.csproj` إلى `net6.0-windows` إذا كان لديك .NET 6 فقط)

## خطوات التشغيل

1. افتح `UniversalPrintServer.sln` في Visual Studio.
2. اضغط F5 أو Build → Run. **سيطلب صلاحيات المسؤول (UAC)** تلقائيًا — هذا
   متعمَّد وضروري (تعديل مشاركة الطابعات وجدار الحماية يتطلبان ذلك).
3. من الواجهة:
   - انسخ عنوان **IP** الظاهر أعلى الشاشة.
   - اختر الطابعة من القائمة.
   - فعّل **إما** مشاركة SMB **أو** شغّل خادم RAW (يمكن تفعيل الاثنين معًا).
4. على الهاتف، في تطبيق UniversalPrinter: "إضافة يدوية" ← اختر البروتوكول
   المطابق (Samba أو RAW/JetDirect) ← أدخل نفس عنوان IP.

## ملاحظات أمنية

- التطبيق يطلب صلاحيات المسؤول لأنه يُعدّل إعدادات نظام حساسة (مشاركة،
  جدار حماية). راجع الكود المصدري بنفسك قبل الثقة به إن أردت — كل شيء
  هنا مفتوح وواضح، لا يوجد أي اتصال بالإنترنت أو جمع بيانات.
- خادم RAW لا يطلب أي مصادقة (تمامًا كطابعات JetDirect الحقيقية) — أي
  جهاز على نفس شبكتك المحلية يمكنه إرسال مهام طباعة إليه طالما يعرف IP
  والمنفذ. هذا سلوك طبيعي لهذا البروتوكول، لكن لا تُشغّله على شبكات
  عامة/غير موثوقة (مثل واي فاي المقاهي).

## هيكل المشروع

```
UniversalPrintServer/
├── App.xaml / App.xaml.cs        نقطة الدخول
├── MainWindow.xaml / .cs          الواجهة الرئيسية
├── app.manifest                    طلب صلاحيات المسؤول
└── Services/
    ├── NetworkInfo.cs               عناوين IP المحلية
    ├── PrinterManager.cs             سرد الطابعات + تفعيل مشاركة SMB
    ├── FirewallHelper.cs              قواعد جدار الحماية (netsh)
    ├── RawPrinterHelper.cs             إرسال بايتات خام عبر winspool.drv
    └── RawPrintListener.cs             خادم TCP على المنفذ 9100
```
